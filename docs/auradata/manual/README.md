# Manual de AuraData BI

AuraData BI es la herramienta de informes de AuraData: conectas tus datos, armas informes de varias páginas con
gráficos, tarjetas y segmentadores, y los compartes con tu equipo. Si vienes de Power BI, casi todo te va a sonar:
lienzo de tamaño fijo, cinta, panel de formato, marcadores, obtener detalles y diseño móvil.

Este manual recorre la aplicación pantalla por pantalla.
